# AE Presets Store

Tienda React/Vite para vender presets de After Effects.

## Instalar

```bash
npm install
npm run dev
```

La página usa `ogl` para el fondo Aurora/WebGL y está preparada para sustituir los previews por imágenes o videos reales de tus presets.

## Personalizar

Edita `src/main.jsx`:
- `products`: nombres, precios y descripciones.
- `Aurora`: colores del fondo.
- Botones `Comprar pack`: conecta aquí tu checkout o sistema de entrega.

El diseño es original y está inspirado en la estética oscura/minimalista de la referencia, no es una copia de la página mostrada.
